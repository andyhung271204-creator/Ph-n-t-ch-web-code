# Mô tả website Xây dựng Gia Khánh

Bộ tài liệu mô tả website **xaydunggiakhanh.vn** đúng như code hiện tại (cập nhật 18/11/2026).

## Website này là gì?

Website giới thiệu **Công ty TNHH Xây dựng và Đầu tư Gia Khánh** (MST 0111442677, trụ sở Đông Anh, Hà Nội), đơn vị xây và sửa nhà ở dân dụng tại Hà Nội.

**Mục tiêu chính:** khách hàng tin tưởng nhanh và để lại liên hệ, bằng một trong bốn cách:

1. Điền form "Nhận báo giá miễn phí"
2. Bấm gọi hotline 0964 531 577
3. Chat Zalo
4. Nhắn Messenger (fanpage)

**Khách hàng mục tiêu:** gia đình ở Hà Nội và các huyện lân cận (Đông Anh, Gia Lâm, Hoài Đức, Thanh Trì, Hà Đông…) đang muốn xây nhà mới, sửa/cải tạo nhà cũ, thiết kế hoặc hoàn thiện nội thất.
